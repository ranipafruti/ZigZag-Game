1. Zig Zag Game

A simple and challenging 3D endless runner game developed using Unity and C#. The player controls a ball moving forward on a zig-zag platform and must change direction at the right time to stay on the path.

2. Features
 
 ->Ball movement
 
 ->Left and right direction control
 
 ->Zig-zag platform
 
 ->Coin collection
 
 ->Score system
 
 ->Game Over system
 
 ->Restart functionality
 
 ->Increasing difficulty
 
 ->Android support

3. Technologies Used
   
->Unity 2022

->C#

->Visual Studio

->GitHub

4. How to Play

->Tap the screen to change the ball's direction.

->Keep the ball on the zig-zag platform.

->Collect coins to increase your score.

->Avoid falling from the platform.

->Try to achieve the highest score possible.

5. Platform
   
->Android
